# DTS Frontend

React 19, TypeScript, Vite ve Tailwind CSS ile hazırlanmış DTS frontend altyapısıdır. Bu sprint yalnızca proje iskeleti, provider yapısı, routing ve ortak klasör düzenini içerir.

## Kurulum

```bash
npm install
```

## Çalıştırma

```bash
npm run dev
```

Varsayılan adres: `http://localhost:5173`

## Build

```bash
npm run build
```

## Kontrol

```bash
npm run lint
```
